# Email Automation Project
This is an email automation project, where the AI agent will log into your email, search for a specific subject, and process the email content into a BRD (Business Requirements Document).

---
# To Run

1. Install google-genai to integrate GEMINI AI API key
```
pip install google-genai
```
2. Run the project
```
python main.py
```
