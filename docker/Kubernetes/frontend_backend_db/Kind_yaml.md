| **Kind**                        | **What `kubectl apply` creates/updates** | **What happens next**                                                                                  | **Verification Commands**                                                                                                                         |
| ------------------------------- | ---------------------------------------- | ------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Deployment**                  | Creates/updates a Deployment             | Deployment controller creates/updates a ReplicaSet, which creates the desired Pods.                    | `kubectl get deployments`<br>`kubectl get rs`<br>`kubectl get pods`<br>`kubectl describe deployment <deployment-name>`                            |
| **Service**                     | Creates/updates a Service                | Gets a ClusterIP (or NodePort/LoadBalancer) and routes traffic to Pods matching its selector.          | `kubectl get services` or `kubectl get svc`<br>`kubectl describe service <service-name>`<br>`kubectl get endpoints <service-name>`                |
| **ConfigMap**                   | Creates/updates a ConfigMap              | Configuration is stored in the cluster and can be mounted or exposed as environment variables to Pods. | `kubectl get configmaps` or `kubectl get cm`<br>`kubectl describe configmap <configmap-name>`<br>`kubectl get configmap <configmap-name> -o yaml` |
| **Secret**                      | Creates/updates a Secret                 | Secret data is stored in the cluster and can be mounted or injected into Pods.                         | `kubectl get secrets`<br>`kubectl describe secret <secret-name>`<br>`kubectl get secret <secret-name> -o yaml`                                    |
| **Ingress**                     | Creates/updates an Ingress               | The Ingress Controller reads the rules and configures HTTP/HTTPS routing to Services.                  | `kubectl get ingress`<br>`kubectl describe ingress <ingress-name>`                                                                                |
| **PersistentVolumeClaim (PVC)** | Creates/updates a PVC                    | Kubernetes binds the PVC to a matching PV (or dynamically provisions one).                             | `kubectl get pvc`<br>`kubectl describe pvc <pvc-name>`<br>`kubectl get pv`                                                                        |
